# Question 1:
## Consider the following ordered array: [2, 4, 6, 8, 10, 12, 13]. How many comparisons would it take to find the number 8 using linear search?
### It would take 4 comparisons to find the number 8 using a linear search algorithm. Linear search would begin by comparing the first array element to the target value (8). Since 2 != 8, the linear search algorithm continues one by one until finding 8 which is the 4th array element.
